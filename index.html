1. Problem Definition & One-Page PRD

아이디어를 넘어 양산(Production) 가치를 증명하는 한 장 기획서 프레임워크입니다.

01. 문제 정의 (Problem)

용접 공정 중 발생하는 자욱한 유증기와 불꽃 스펙큘러로 인해 기존 비전 카메라의 가짜 객체 오검출율이 14%에 달함.

02. 사용자 시나리오

현장 안전관리자가 엣지 대시보드를 통해 불꽃 오검출 경보를 즉시 확인하고, 4축 로봇에 비상 정지(STOP) 제어 신호 전달.

03. 성공 지표 (KPI)
  • • 추론 지연시간: < 25ms
  • • 모델 mAP@50: > 91.5%
  • • 연속 가동률: 99.9%
04. 핵심 기술 스택

YOLO26 + ONNX Runtime, OpenCV (CLAHE), ESP32-S3 (MQTT), Docker, FastAPI

05. Scope / Thin-Slice

In-Scope: 1개 라인 안전모/작업자 정밀 검출.
Out-of-Scope: 전사 클라우드 ERP 연동.

06. ROI 한 줄 증명

PoC 구축 비용 2,000만 원 대비 오동작 방지로 연간 4억 2천만 원 손실 예방 (회수기간: 0.6개월)

2. Field Environment Analysis (5-Env)

현장의 물리적 악조건을 사전 분석하여 전처리 및 방어 로직을 구축했습니다.

현장 노이즈 분석 체크시트

환경 요소 현장 상태 적용 전처리/보정
1. 광학 (Optical) 용접 불꽃 반사광 CLAHE (적응형 평등화)
2. 오염 (Noise) 분진 및 유증기 시야 방해 Morphology Open/Close
3. 기계 (Motion) 로봇 팔 12Hz 진동 Sharpening + Dynamic ROI
4. 센서 (Sensor) 1080p 60FPS Raw Data 640x640 Downsampling

Production-ready 전처리 파이프라인

Fail-fast 검증, 예외 처리, 지연시간 측정이 포함된 파이썬 모듈 코드입니다.

class PreprocessPipeline:
    def run(self, frame):
        # 1. Fail-Fast 데이터 검증
        if frame is None: raise ValueError("Corrupted Frame")
        
        # 2. 광학 노이즈 제거 (CLAHE)
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        enhanced = self.clahe.apply(gray)
        
        # 3. 엣지 디바이스 용 Resize (Memory reuse)
        resized = cv2.resize(enhanced, (640, 640))
        return resized
